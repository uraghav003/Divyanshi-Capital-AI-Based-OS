# Divyanshi Capital CRM & BULBHUL OS

The ultimate high-speed enterprise platform for **Divyanshi Capital AI Workspace OS (P1 Business Runtime)**. Designed under the strict MALLIK MASTER OS Protocol.

## 🚀 Key Architectural Layout

- **P1 Runtime (React & Express + Vite)**: Operating engines powered by real-time streams, secure OTP ingress gateways, and dynamic workflow dashboards.
- **Google Apps Script (GAS) Backend**: Direct integrations with Google Sheets (`Code.gs`) acting as the reliable database and CRM hub.
- **BULBHUL & SARI Advisors**: Active monitoring nodes with auditory feedback loops, built-in financial calculators, live leads management, and automatic compliance audits.
- **LAILA Secure Ingress**: Auditable activity tracking, multi-point validation gates, and interactive security consoles.

## 📦 GitHub Repository & Deployment

This repository is structured for streamlined execution and GitHub integration:
- **`.github/workflows/deploy-gas.yml`**: Automates Google Apps Script pushes directly via `clasp`.
- **`.github/workflows/verify-and-clean.yml`**: Ensures clean logic, syntax checks, and deduplication verification.
- **`.clasp.json` & `.claspignore`**: Configured to sync `Code.gs` flawlessly to the Apps Script environment without deploying unnecessary frontend node modules.
